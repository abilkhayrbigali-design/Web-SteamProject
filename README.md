# Steam Game Hub

Статический сайт команды **Eggs**, группа **SE-2507**, для Assignment 2 по Web Technologies I.

## Сайт

Адрес GitHub Pages после публикации: https://chinusoid.github.io/Web-SteamProject/

Для локального запуска откройте `index.html`. Сборка и установка зависимостей не нужны.

## Что реализовано

- Восемь страниц с общей навигацией через Flexbox.
- Карточки одинаковой высоты, рабочие переходы и эффекты наведения.
- Grid-макет с именованными областями header, sidebar, main и footer.
- Галереи из девяти изображений, подписи при наведении и фокусе.
- Адаптивная вёрстка, клавиатурная навигация и reduced motion.
- Официальные обложки игр, сохранённые локально; картинка Dota 2 сохранена из исходной версии.
- Демонстрационные формы с локальной валидацией, без отправки данных на сервер.

Основные стили задания находятся в `css/assignment.css`. Источники изображений: [IMAGE_SOURCES.md](IMAGE_SOURCES.md).

## Проверка

Проверены восемь страниц на ширинах 1440, 1200, 1024, 768, 700, 620, 375 и 320 px.
Проверены изображения, ссылки, Grid-области, одинаковая высота карточек, формы и галереи.

## Обновление GitHub Pages

Публикуется корень ветки `main`. Изменения сайта, отправленные в эту ветку, запускают новую публикацию.
